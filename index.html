루팡 윈
사용 안내다운로드

공문 업무를 덜고,수업에 더 가까이.

루팡 윈은 Windows에서 공문을 정리하고 문서 작업을 돕는 선생님의 공문 비서입니다.

Windows 설치 파일 받기 사용 안내 보기

최신 버전 1.3.4, 64비트 Windows, 변경 내용 보기

설치는 간단하게,
업데이트는 안전하게.

현재 설치 파일과 변경 내용은 이 공식 배포 페이지에서 확인할 수 있습니다. 새 버전이 나오면 같은 위치에 게시합니다.

01

공식 안내 확인

이 페이지에서 현재 버전과 업데이트 내용을 확인합니다.

02

설치 파일 받기

공식 GitHub Releases에서 설치 파일을 내려받아 실행합니다.

03

기존 설정 유지

업데이트 설치는 기존 사용자 설정과 처리 기록을 보존하도록 설계되어 있습니다.

Windows용
프로그램

루팡 윈은 Windows 데스크톱 설치 프로그램으로 제공됩니다. Mac 버전은 별도 프로젝트이며 이 배포 페이지에서 제공하지 않습니다.
