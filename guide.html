루팡 윈배포 페이지로

설치와 사용 안내

Windows용 루팡 윈을 설치하고 설정하는 방법입니다. 첫 공개 설치 파일이 게시되면 이 안내에 실제 다운로드 링크와 설치 화면을 추가합니다.

첫 공개 설치 파일은 아직 준비 중입니다.현재 공개 배포 페이지와 설명서를 먼저 열었습니다. 파일이 게시되기 전에는 비공식 링크에서 설치 파일을 내려받지 마세요.

설치 전 확인

운영체제Windows 10 이상을 기준으로 합니다.
사용자 권한현재 사용자 계정에 설치하는 방식으로 준비 중입니다.
한컴오피스한글 문서 변환 기능을 쓰려면 PC에 한컴오피스가 필요합니다.
설치 파일공식 배포 페이지의 GitHub Releases에서 받을 예정입니다.

처음 설치

  1. 공식 페이지에서 최신 버전과 변경 내용을 확인합니다.
  2. 설치 EXE를 내려받아 실행합니다.
  3. 설치 화면에서 공문 폴더, 변환 결과 폴더, AI 요약과 알림을 설정합니다.
  4. 설치가 끝나면 루팡 윈을 열고 설정 화면에서 선택 사항을 확인합니다.

화면 구성과 설치 절차는 첫 공개 설치 파일에 맞춰 확정한 뒤 보완합니다.

업데이트

새 버전이 나오면 홈페이지와 공개 릴리스에 버전, 변경 내용, 설치 파일을 올릴 예정입니다. 앱 내 업데이트 확인은 배포 시스템과 연결한 뒤 안내합니다.

  1. 공식 페이지에서 새 버전인지 확인합니다.
  2. 설치 파일을 내려받아 실행하고 안내에 따라 업데이트합니다.
  3. 설치 중 문제가 생기면 업데이트 전에 중요한 설정과 데이터를 백업합니다.

현재 버전에서는 자동 다운로드나 백그라운드 설치가 연결되어 있지 않습니다.

개인정보와 보안

공문에는 개인정보가 포함될 수 있습니다. AI 기능을 사용할 때에는 실제 문서를 전송하기 전에 설정과 개인정보 처리 방식을 확인하세요. API 키와 알림 토큰을 공개 페이지, 문의 글, 화면 캡처에 포함하지 마세요.

공식 다운로드와 변경 내역은 공개 릴리스 페이지에서 확인할 수 있습니다.
