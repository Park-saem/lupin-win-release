# 루팡 윈 배포 페이지

이 공개 저장소는 루팡 윈 사용자에게 설치 파일, 업데이트 안내, 사용 설명서를 제공하는 배포 채널입니다. 프로그램 소스 코드는 포함하지 않습니다.

- 홈페이지: https://park-saem.github.io/lupin-win-release/
- 사용 안내: https://park-saem.github.io/lupin-win-release/guide.html
- 업데이트 정보: https://park-saem.github.io/lupin-win-release/latest.json

## 현재 상태

공개 페이지와 설명서는 준비 중입니다. 아직 설치 파일이 게시되지 않았고, 앱 내 업데이트 확인도 연결되지 않았습니다. 설치 파일이 준비되면 GitHub Releases에 올리고 `latest.json`의 버전과 다운로드 주소를 갱신합니다.

## 공개 원칙

이 저장소에는 공개해도 되는 홈페이지·설명서·업데이트 정보와 배포 파일만 둡니다. 비공개 소스 저장소, 사용자 설정, 로그, API 키는 올리지 않습니다.

## Pages

GitHub Actions가 `main` 브랜치의 정적 파일을 GitHub Pages로 게시합니다. 저장소 Settings → Pages에서 Source를 `GitHub Actions`로 설정해야 합니다.
